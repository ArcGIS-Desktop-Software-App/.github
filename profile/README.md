## Overview
ArcGIS Desktop for Windows is Esri's long-standing desktop GIS software, giving analysts a full set of tools for managing geographic data, running spatial analysis, and producing polished arcgis maps. It's used across government, utilities, and academic GIS programs that need a dependable arcgis software package for everyday mapping work, from digitizing features to publishing finished layouts.

## Features
| Feature | What it does for you |
|---|---|
| Map authoring | Build layered maps from vector, raster, and tabular data |
| Geoprocessing toolbox | Run spatial analysis tools against your own datasets |
| Geodatabase editing | Create and edit features inside a personal or enterprise geodatabase |
| Broad format support | Bring in shapefiles, CAD files, and raster imagery |
| Cartographic layout | Design and export print-ready or shareable maps |

> Esri continues to maintain ArcGIS Desktop while investing further development effort in ArcGIS Pro, so expect its desktop GIS tools to keep evolving alongside the wider Esri platform over time.

## Getting Started
Open ArcMap and start a new map document, then add a data source such as a shapefile or geodatabase layer to see it rendered on the map. From there, adjust the layer's symbology, try a basic tool from the geoprocessing toolbox, and save your work as you go so nothing gets lost between sessions.

## FAQ
- [ ] **Is arcgis free?** — No, ArcGIS Desktop is commercial software that requires a paid Esri license; trial access may be available for evaluation.
- [ ] **Which versions of Windows are supported?** — Recent 64-bit releases of Windows, per Esri's published system requirements.
- [ ] **Is my data secure?** — Your geographic data lives locally in files or geodatabases you control, and nothing leaves your machine unless you choose to share it.
